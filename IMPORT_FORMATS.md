# Import Format Policy

Books: PDF and EPUB initially; DRM is not bypassed.

Images: JPEG, PNG, WebP and platform-supported image formats.

Documents: PDF, DOCX, TXT, Markdown, HTML and CSV initially.

Notes: portable exports such as Markdown/TXT plus supported provider exports.

Google Keep: Google Takeout is the primary migration path.

Archives: ZIP may be accepted as a bundle, with decompression/path-safety limits.

Unsupported formats should be clearly reported and never silently discarded.
